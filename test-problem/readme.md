# Вопрос с вариантами ответа

Официальный сценарий: [создать тестовую задачу](https://admin.contest.yandex.ru/docs/ru/examples/test).

1. Задачи → Создать задачу. Короткое имя нужно для поиска и для правил видимости, участники его не видят.
2. Тип задачи — `TEST_PROBLEM`.
3. Тип ответа: «Один вариант» или «Несколько вариантов». В первом режиме верным может быть только один пункт.
4. Добавьте формулировки и в столбце «Верно?» отметьте правильные.
5. Условие: Markdown + KaTeX, язык `ru` или `en`.

Стандартная проверка считает ответ верным при полном совпадении выбранных пунктов с отмеченными. Вердикт OK или WA, частичных баллов у неё нет.

## Частичные баллы

Свой чекер подключается так же, как у задачи по программированию: [чекеры](https://admin.contest.yandex.ru/docs/ru/problem/checkers). Тип `TESTLIB_EXITCODE_CHECKER`, опция «Чекер выставляет баллы» включена. Аргументы: файл с вариантами, файл с выбором участника, файл с верными номерами.

При вердикте OK первое число первой строки вывода становится баллом теста. Код `1` — WA, код `2` — PE. Баллы не начисляются, если вердикт не OK.

Готовые формулы лежат в [at-testlib](https://github.com/atolstikov/testlib):

- `checkers/points_Jaccard_index.py` — пересечение выбранных и верных, делённое на их объединение;
- `checkers/points_share_of_checked_right.py` — доля пунктов, отмеченных правильно, включая верно не отмеченные.

Оба завершаются через `quitp`, то есть код выхода 0 и строка, начинающаяся с балла. Монитор соревнования — `SCORING`, иначе балл чекера не попадёт в таблицу.
