Это технический пример проверки готовых предсказаний. Здесь не требуется обучать модель: признаки объектов и обучающий датасет не выдаются. Цель — подготовить CSV нужного формата и увидеть балл, рассчитанный по скрытым правильным ответам.

## Что сдать

Загрузите сам CSV-файл, например `predictions.csv`, а не программу, которая его создаёт. Файл должен содержать ровно 3140 строк и один столбец, без заголовка, индекса и пустых строк. В каждой строке — одно число: 0 или 1. Строка с номером `i` соответствует объекту с номером `i`.

## Как подготовить допустимый пример

Следующий код создаёт файл с 3140 нулевыми предсказаниями:
```python
with open("predictions.csv", "w", encoding="utf-8") as f:
    f.write("0\n" * 3140)
```
Это пример формата, а не качественная модель. Такой файл может получить 0 баллов.

## Оценивание

Проверяющая программа сравнивает предсказания со скрытыми метками и вычисляет F1 для положительного класса 1. Балл равен

`max(0, min(2, (F1 - 0.5) / 0.16))`.

Максимум — 2 балла. Корректный файл может получить 0 баллов; неверный формат приводит к неверному ответу.

Имена `test.csv` и `answers.csv` в технических параметрах относятся к работе проверяющей системы. Участнику не нужно создавать эти файлы: сдаётся только CSV с предсказаниями.
