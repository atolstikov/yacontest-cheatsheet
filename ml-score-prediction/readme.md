# Метрика по файлу участника

Участник сдаёт CSV с предсказаниями. На запуске `score.py` считает F1 по скрытому `true_answers.csv` и пишет одно число в `answers.csv`. Чекер `pointscmp.cpp` ставит это число баллами теста. Ошибка формата — строка, которая целиком не является числом: чекер завершается с WA и этим текстом.

Шкала примера: форма ровно `(3140, 1)` без заголовка, баллы `clip((f1 - 0.5) / 0.16, 0, 2)`. Ноль баллов — это всё равно вердикт OK: для метрики важен балл, а не WA.

## Настройки задачи

Тип `PROBLEM_WITH_CHECKER`. Компилятор `make`, в образе должны быть `numpy`, `pandas` и `sklearn`.

Файлы ввода и вывода: вход не используется, выход — файл `answers.csv`. Стандартные потоки выключены, создание файлов включено. Имя `answers.csv` в `score.py` и в настройках задачи должно совпадать: чекер читает выход задачи, а не произвольный файл рядом со скриптом.

Файлы компиляции, в этом порядке: `Makefile`, `build.sh`, `run.sh`, `score.py`, `true_answers.csv`.

Файлы запуска, в этом порядке: `run.sh`, `score.py`, `true_answers.csv`.

Один тест `tests/01` с пустым ответом `tests/01.a`. Содержимое теста скрипт не читает: тест нужен, чтобы система вообще вызвала `run`.

Чекер: скомпилировать `pointscmp.cpp` компилятором GNU GCC, тип `TESTLIB_EXITCODE_CHECKER`, «Чекер выставляет баллы» включено. Во время компиляции доступен встроенный `testlib.h`.

Постпроцессор: первым `postprocessor.py`, окружение Python 3. Он суммирует баллы тестов с вердиктом `ok` и печатает сумму первой строкой. Поле `message`, которого нет в [описании JSON](https://admin.contest.yandex.ru/docs/ru/problem/postprocessors), больше не разбирается.

Соревнование: монитор `SCORING`. В отчёте по посылке включите «Вывод чекера», чтобы участник видел текст WA. «Вывод постпроцессора» нужен, только если хотите показать строки после балла.

## Если проверка падает

- Баллы не появляются в таблице: тип монитора не `SCORING` или у чекера выключена передача баллов.
- Crash: чекер не задан, `pointscmp` не скомпилирован, в задаче нет теста, либо `score.py` завершился не с нулём. Скрипт оценки завершается с нулём даже при плохом файле участника, чтобы вердикт выставил чекер, а не среда запуска.
- Участник видит пустой WA: выходной файл задачи не `answers.csv` или включён stdout, и чекер прочитал пустой поток.
