# Правила видимости задач

Используйте правила соревнования, чтобы открывать задачи по времени или после действий участника. Это настройка набора, а не отдельная задача с чекером.

## Подготовьте правила

1. Выпишите короткие имена задач из настроек. В JSON используйте именно их, а не отображаемые названия. После переименования задач обновите все ссылки в правилах.
2. Выберите условия показа и скрытия из таблицы ниже.
3. Создайте JSON с корневым полем `rules`: массивом правил. В каждом правиле задайте `problem` — короткое имя целевой задачи.
4. Убедитесь, что зависимости не образуют циклов.
5. Откройте в соревновании «Задачи → Правила видимости задач», загрузите JSON и проверьте сохранённое содержимое.

## Выберите условия

| Поле | Назначение |
| --- | --- |
| `visibleSince` | Показывать начиная с указанного момента |
| `visibleDuring` | Скрыть после указанного момента |
| `hideWhenSolved` | Скрыть после решения |
| `hideWhenAttempted` | Скрыть после попытки |
| `shouldBeSolved` | Показать, если задачи из списка решены |
| `shouldNotBeSolved` | Показать, если задачи из списка не решены |
| `shouldBeAttempted` | Показать, если по задачам из списка были попытки |
| `shouldNotBeAttempted` | Показать, если по задачам из списка не было попыток |

Время задавайте в миллисекундах от старта соревнования. `visibleDuring` — момент на этой шкале, а не длительность после `visibleSince`.

Для `hideWhenSolved` и `hideWhenAttempted` задайте `value: true` и `scope`: `local` для текущего участника или `global` для любого участника.

Для зависимостей задайте `value` — список коротких имён, `quantifier` — `all` (все) или `any` (хотя бы одна), и `scope` — `local` или `global`. Не используйте поле `shouldNotBeVisible`: в описанном формате его нет.

## Настройте простой пример

Покажите A с 15-й до 30-й минуты и скройте после решения текущим участником. Откройте B, когда A решит любой участник:

```json
{
  "rules": [
    {
      "problem": "A",
      "visibleSince": 900000,
      "visibleDuring": 1800000,
      "hideWhenSolved": {"scope": "local", "value": true}
    },
    {
      "problem": "B",
      "shouldBeSolved": {"scope": "global", "value": ["A"], "quantifier": "all"}
    }
  ]
}
```

## Настройте разминку и основной набор

Файл [rules-2-subsets.json](rules-2-subsets.json) рассчитан на короткие имена `0`, `1`–`12` и `A`–`L`:

- `0` видна первые 30 минут и скрывается у участника после попытки или решения.
- `1`–`12` видны те же 30 минут, пока по `0` нет попытки.
- `A`–`L` открываются на 30-й минуте.

Перед загрузкой замените имена и время под свой набор. Не используйте скрытие одной задачи как событие открытия другой: задайте зависимость от решения, попытки или времени явно.

## Проверьте результат

Откройте соревнование обычным аккаунтом участника. Проверьте видимость до и после временной границы, затем после попытки и решения зависимой задачи. Для `local` и `global` используйте два тестовых участника, чтобы проверить, чьи действия меняют видимость.

Если задача не появляется, сверьте короткие имена, единицы времени, `scope`, `quantifier` и отсутствие циклов. Не проверяйте участническую видимость только администраторским аккаунтом.
