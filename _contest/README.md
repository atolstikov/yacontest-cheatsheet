# Материалы для настройки соревнования

Используйте эти материалы при подготовке соревнования и решений участников:

- [Правила видимости](visibility-rules/readme.md) — открытие и скрытие задач по времени, попыткам и решениям.
- [Шаблон Python](solution-templates/template_stdin.py) и [шаблон C++](solution-templates/template_stdin.cpp) — заготовки чтения стандартного ввода.

Адаптируйте правила и шаблоны под формат своей задачи. Они не входят в ZIP рецептов и не загружаются упаковщиком автоматически.

[К рецептам и общей инструкции](../README.md).
