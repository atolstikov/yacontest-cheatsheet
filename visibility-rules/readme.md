# Правила видимости задач

Правила задаются в соревновании: задачи → «Правила видимости задач» → загрузить JSON. После загрузки файл можно скачать и открыть под кнопкой. Описание полей: [задачи соревнования](https://admin.contest.yandex.ru/docs/ru/contest/problems).

В файле один объект `rules` — массив правил. У каждого правила обязательное поле `problem`: короткое имя задачи.

Показать и скрыть по времени, миллисекунды от старта соревнования:

- `visibleSince` — показать не раньше этого момента;
- `visibleDuring` — скрыть после этого момента. Это момент на шкале от старта, а не длительность после `visibleSince`.

Скрыть саму задачу:

- `hideWhenSolved` — после решения;
- `hideWhenAttempted` — после попытки.

Оба поля содержат `value: true` и `scope`: `local` для текущего участника, `global` для любого участника соревнования.

Показать задачу в зависимости от других. У условия есть `value` — список коротких имён, `quantifier` (`all` или `any`) и `scope` (`local` или `global`):

- `shouldBeSolved` — когда задачи из списка решены;
- `shouldNotBeSolved` — когда не решены;
- `shouldBeAttempted` — когда по ним были попытки;
- `shouldNotBeAttempted` — когда попыток не было.

`any` означает «хотя бы одна задача из списка», `all` — «все». В зависимостях не делайте циклов: задача A не должна ждать B, если B ждёт A.

Поля `shouldNotBeVisible` в этом списке нет. Старый `rules-2-subsets.json` на него опирался, поэтому файл переписан.

Пример из документации. Задача A видна с 15-й по 30-ю минуту и скрывается после решения текущим участником. Задача B появляется, когда задачу A решит любой участник:

```json
{
  "rules": [
    {
      "problem": "A",
      "visibleSince": 900000,
      "visibleDuring": 1800000,
      "hideWhenSolved": {
        "scope": "local",
        "value": true
      }
    },
    {
      "problem": "B",
      "shouldBeSolved": {
        "scope": "global",
        "value": ["A"],
        "quantifier": "all"
      }
    }
  ]
}
```

## Два слоя в rules-2-subsets.json

Файл рассчитан на короткие имена `0`, `1`–`12` и `A`–`L`.

- `0` видна первые 30 минут и скрывается у участника после попытки или решения.
- `1`–`12` видны те же 30 минут, но только пока по `0` нет попытки.
- `A`–`L` появляются на 30-й минуте, по `visibleSince`.

Раньше конкурсный слой открывался сразу, как только скрывались и `0`, и `1`, в том числе если участник закрывал разминку попыткой раньше получаса. Текущие поля так не умеют: момент скрытия одной задачи нельзя использовать как условие показа другой. Теперь конкурсный слой привязан ко времени.
