Напишите Python-программу с использованием `requests`, которая обращается к локальному HTTP-сервису и выводит данные из его JSON-ответа. Сервер запускает проверяющая система; доступ к внешним сайтам не нужен.

## Запрос и ответ

Прочитайте адрес сервера, порт и два целых числа `a` и `b`. Отправьте GET-запрос на адрес `сервер:порт`, передав `a` и `b` как параметры запроса с именами `a` и `b`. Например:
```text
http://127.0.0.1:7777?a=4&b=2
```
Сервер вернёт JSON-объект с двумя полями: `result` — список из частного целочисленного деления и остатка, `check` — проверочная строка. Например:
```text
{"result": [2, 0], "check": "example-token"}
```
Отсортируйте полученный список по возрастанию. Проверочную строку скопируйте из ответа без изменений: вычислять её самостоятельно не нужно. Значение `example-token` здесь условное, в тестах строки другие.

## Что сдать

Сдайте один Python-файл, который читает стандартный ввод и печатает результат в стандартный вывод. Не запускайте собственный сервер.

## Оценивание

100 баллов за прохождение всех шести тестов, иначе 0.

## Формат ввода

Четыре строки: адрес сервера со схемой `http://` (без порта), порт, целое число `a`, целое ненулевое число `b`. Например:
```text
http://127.0.0.1
7777
4
2
```

## Формат вывода

В первой строке выведите два числа из `result` по возрастанию через один пробел. Во второй — строку `check`. Не печатайте скобки, кавычки, JSON или пояснения.

Для условного JSON-примера выше вывод имеет вид:
```text
0 2
example-token
```
