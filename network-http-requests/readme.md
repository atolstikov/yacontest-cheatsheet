# HTTP-клиент к серверу задачи

[Условие для участника](statement.md) · [Сборка и импорт задачи](../_packaging/README.md).

Используйте рецепт, чтобы проверять HTTP-запросы участника к локальному сервису внутри окружения Контеста. Доступ к внешней сети не требуется.

## Что сдаёт участник

Python-скрипт читает четыре строки: адрес сервера, порт, целые числа `a` и `b`. Он отправляет GET-запрос с параметрами `a` и `b`, разбирает JSON и печатает:

1. Элементы массива `result` в порядке возрастания через пробел.
2. Строку `check` без изменений.

Сервер возвращает в `result` частное `a // b` и остаток `a % b`. Образец — [solution.py](solution.py).

[test.py](test.py) запускает сервер на `127.0.0.1:7777`, ждёт его готовности, запускает решение и завершает сервер после проверки. Логи сервера не попадают в stdout решения.

## Настройте задачу

Выберите `PROBLEM_WITH_CHECKER`, компилятор `make` и образ с Python, Flask, requests и flake8.

| Настройка | Значение |
| --- | --- |
| Ввод / вывод | stdin и stdout включены |
| Файлы компиляции | `Makefile`, `build.sh`, `check.py` |
| Файлы запуска | `run.sh`, `test.py`, `server.py` |
| Чекер | `STANDARD_CHECKER`, `cmp_file` |
| Постпроцессор | Python; `postprocessor.py` |
| Тесты в ZIP | `tests/01`–`tests/06`, маска `tests/{01-}`, ответы `*.a` |
| Монитор | `SCORING` |

Не добавляйте образец `solution.py` к файлам запуска: его создаёт сборка из посылки. При упаковке локальные тесты `001`–`006` переименовываются в `01`–`06`; маску задавайте по содержимому ZIP.

## Настройте баллы

Стандартный чекер сравнивает вывод с `.a`. Постпроцессор по умолчанию начисляет 100 за все тесты и 0 иначе. Для доли пройденных тестов установите `DIFFERENT = True` и отключите оба прерывания при первой ошибке.

При замене протокола согласуйте `server.py`, входы, ответы и образец решения. Оставьте отладчик Flask и reloader выключенными, чтобы не создавать лишние процессы.

## Проверьте результат

Отправьте образец: ожидайте OK/100. Затем отправьте решение с неправильным выводом: ожидайте WA/0. Проверьте, что процесс сервера завершается между тестами.

При ошибке запуска проверьте зависимости и время ожидания готовности сервера. При WA сверьте адрес, порт, формат двух строк и отсутствие логов в stdout. При ошибке flake8 используйте CLI с `--jobs=1`.

## Соберите и загрузите файлы

Из корня репозитория выполните:

```sh
python _packaging/package_recipe.py --check network-http-requests
python _packaging/package_recipe.py network-http-requests
```

Загрузите `dist/network-http-requests.zip` в корень файлов задачи. Назначьте роли файлов из таблицы выше в указанном порядке; архив сам не применяет настройки. Скрипты храните с LF. Сверьте старые файлы и активные тесты: ZIP не удаляет отсутствующие в нём пути.
