# HTTP-запрос к серверу задачи

`test.py` поднимает `server.py` на `127.0.0.1:7777`, дожидается ответа и запускает `solution.py`, передавая ему stdin теста. Логи Flask отбрасываются: иначе баннер сервера попадает в stdout и `cmp_file` даёт WA. Сервер по параметрам `a` и `b` возвращает частное, остаток и контрольную строку. Вывод решения сравнивается с файлом ответа стандартным чекером `cmp_file`.

`debug=True` у Flask больше не используется: отладчик поднимал второй процесс, и `kill` не останавливал сервер. `test.py` завершает сервер в `finally` и возвращает код выхода решения.

Тесты: `tests/001`–`006`.

## Настройки задачи

Тип `PROBLEM_WITH_CHECKER`. Компилятор `make`. В образе нужны `python3`, `flask` и `requests`.

Стандартный ввод и стандартный вывод включены.

Файлы компиляции, в этом порядке: `Makefile`, `build.sh`, `check.py`. Сборка копирует посылку в `solution.py` и запускает `flake8`. Нет `flake8` в образе — будет CE; уберите вызов `check.py` из `build.sh`, если проверка стиля не нужна.

Файлы запуска, в этом порядке: `run.sh`, `test.py`, `server.py`.

Чекер: тип `STANDARD_CHECKER`, ID `cmp_file`. Он сравнивает файлы построчно и выбран в документации по умолчанию.

Постпроцессор необязателен: `cmp_file` даёт OK или WA. `postprocessor.py` ставит `100`, только если прошли все тесты, и `0` иначе. Для такого балла нужен монитор `SCORING`. Чтобы учитывать долю тестов, поставьте в файле `DIFFERENT = True` и выключите прерывание при первой ошибке.

## Если проверка падает

- Crash: нет теста, чекер не выбран, сервер не открыл порт за 10 секунд.
- WA при верном решении: сервер и решение смотрят на разные хост или порт. Тест задаёт их первыми двумя строками, образец `solution.py` читает их из stdin.
- CE: нет `flask`, `requests` или `flake8` в образе компилятора `make`.
