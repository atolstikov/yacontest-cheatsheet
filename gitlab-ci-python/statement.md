Реализуйте функцию `clamp(value, lower, upper)` в файле `solution.py`.

Функция ограничивает число отрезком `[lower, upper]`:

- Если число меньше нижней границы, верните `lower`.
- Если число больше верхней границы, верните `upper`.
- В остальных случаях верните само число.
- Если `lower > upper`, вызовите исключение `ValueError`.

Аргументы — конечные целые или вещественные числа. Границы включены; они могут совпадать. Стандартный ввод читать не нужно, функция возвращает число.

## Примеры

```python
clamp(5, 0, 10)       # 5
clamp(-2, 0, 10)      # 0
clamp(12, 0, 10)      # 10
clamp(4, 3, 3)        # 3
clamp(5, 10, 0)       # ValueError
```
