# Юнит-тесты на Python

Участник сдаёт модуль с функцией `evaluate_expression`. `run_tests.py` прогоняет `unittest` и последней строкой stdout печатает балл: сложение, вычитание и умножение по 1, деление 2. Чекер читает эту строку.

Это тот же пайплайн, что в [документации](https://admin.contest.yandex.ru/docs/ru/examples/advanced-usage/default-tests-for-language). Раньше `run.sh` перенаправлял stdout в `tests.log`, и чекер получал пустой вывод. Теперь лог тестов и балл идут в stdout, как в официальном примере.

## Настройки задачи

Тип `PROBLEM_WITH_CHECKER`. Компилятор `make`. Если тестам нужны `numpy` или `pandas`, выберите образ, в котором они есть.

Стандартный ввод не нужен. Стандартный вывод включён: чекер читает именно его. Отдельный файл вывода не задавайте.

Файлы компиляции, в этом порядке: `Makefile`, `build.sh`.

Файлы запуска, в этом порядке: `run.sh`, `run_tests.py`.

Файл `expression.py` из репозитория — образец решения для локального прогона. В задачу его не кладите: `build.sh` записывает посылку поверх этого имени.

Один пустой тест `tests/01` и пустой `tests/01.a`.

Чекер: тип `TESTLIB_EXITCODE_CHECKER`, «Чекер выставляет баллы» включено. Файлы чекера: сначала `check_py`, затем `score.py`. `check_py` вызывает `score.py` с тремя путями. Скрипт берёт последнее число stdout. Ноль баллов и пустой вывод — WA с кодом 1, нечисловая строка — PE с кодом 2, иначе печатает балл и завершается с кодом 0.

`DEADLINE` в `score.py` по умолчанию `None`. Дата `2020-02-29` из старого примера сейчас всегда срезала бы балл до половины. Чтобы включить штраф, запишите в `DEADLINE` дату дедлайна: каждый начатый день после неё умножает балл на `1 - 0.1 * дни`, но не ниже `0.5`.

Соревнование: монитор `SCORING`. «Вывод» в отчёте показывает лог `unittest` вместе с последней строкой-баллом.

## Если проверка падает

- Баллы не появляются: монитор не `SCORING` или выключено «Чекер выставляет баллы».
- Crash: нет чекера, нет теста, либо `score.py` упал до `sys.exit`.
- CE `missing separator`: в `Makefile` вместо табов стоят пробелы.
- Ноль баллов при живых тестах: последняя строка stdout — не число. Так бывает, если `run.sh` снова перенаправит вывод в файл.
