Реализуйте функцию, которая вычисляет арифметическое выражение с двумя целыми неотрицательными числами и одной операцией: +, -, * или /. В строке нет пробелов. Результат вычитания может быть отрицательным.

## Что сдать

Сдайте один Python-файл с функцией:
```python
def evaluate_expression(expression):
    # Верните результат выражения.
    ...
```
Проверяющая программа импортирует модуль и вызывает функцию. Не читайте стандартный ввод и не печатайте ответ: функция должна вернуть число.

Для деления используйте обычное деление Python: результат может быть дробным. При делении на ноль функция должна вызвать исключение `ZeroDivisionError`, а не вернуть строку или специальное значение.

## Примеры вызовов
```python
evaluate_expression("1+1")  # 2
evaluate_expression("0-2")  # -2
evaluate_expression("2*2")  # 4
evaluate_expression("1/1")  # 1.0
evaluate_expression("1/0")  # исключение ZeroDivisionError
```

## Оценивание

Проверка состоит из четырёх групп unit-тестов. Сложение, вычитание и умножение дают по 1 баллу; деление, включая деление на ноль, — 2 балла. Баллы за группу начисляются, только если пройдены все её проверки. Максимум — 5 баллов. Можно получить частичный зачёт.
