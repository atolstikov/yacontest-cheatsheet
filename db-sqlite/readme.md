# Запрос к SQLite

[Условие для участника](statement.md) · [Сборка и импорт задачи](../_packaging/README.md).

Используйте рецепт, чтобы проверять запрос к готовой базе данных через Python-скрипт участника.

## Что сдаёт участник

Скрипт читает из stdin имя SQLite-базы и печатает названия драм продолжительностью меньше 90 минут, по одному на строку. Записи с пустой продолжительностью исключаются. Образец — [solution.py](solution.py).

Чекер сравнивает список строк с результатом эталонного запроса, включая порядок. Пустые строки и пробелы по краям строк игнорируются. Если меняете запрос, явно задайте требуемый порядок и согласуйте SQL в решении и чекере.

## Настройте задачу

Выберите `PROBLEM_WITH_CHECKER`, компилятор `make` и образ с Python и flake8. Модуль sqlite3 входит в стандартную библиотеку Python.

| Настройка | Значение |
| --- | --- |
| Ввод / вывод | stdin и stdout включены |
| Файлы компиляции | `Makefile`, `build.sh`, `check.py` |
| Файлы запуска | `run.sh`, `films0.db`, `films1.db`, `films2.db` |
| Тип чекера | `TESTLIB_EXITCODE_CHECKER`, «Чекер выставляет баллы» выключено |
| Окружение и файлы чекера | Python; `compare_result.py` первым, затем все три БД |
| Постпроцессор | Python; `postprocessor.py` |
| Тесты | `tests/001`–`tests/003`, маска `tests/{001-}`, ответы `*.a` |
| Монитор | `SCORING` |

Базы добавьте и в файлы запуска, и в файлы чекера: это разные окружения. Вход теста содержит имя базы. Файлы `.a` оставьте в комплекте, хотя эталонный список чекер вычисляет сам.

## Настройте баллы

В [postprocessor.py](postprocessor.py) оставьте `DIFFERENT = False` для 100 баллов за все тесты и 0 иначе. Для доли пройденных тестов установите `DIFFERENT = True` и отключите прерывание при первой ошибке в задаче и наборе тестов. Набор `samples` в этом режиме исключается из расчёта.

## Проверьте результат

Отправьте образец решения: ожидайте OK/100. Затем отправьте скрипт с неправильным или пустым выводом: ожидайте WA/0. Сверьте все три теста и итоговый балл.

Если чекер падает, проверьте наличие БД среди его файлов. Если получаете WA, сверьте фильтр, порядок строк и отсутствие служебного текста в stdout.

## Соберите и загрузите файлы

Из корня репозитория выполните:

```sh
python _packaging/package_recipe.py --check db-sqlite
python _packaging/package_recipe.py db-sqlite
```

Загрузите `dist/db-sqlite.zip` в корень файлов задачи. Назначьте роли файлов из таблицы выше в указанном порядке; архив сам не применяет настройки. Скрипты храните с LF. Сверьте старые файлы и активные тесты: ZIP не удаляет отсутствующие в нём пути.
