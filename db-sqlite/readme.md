# Запрос к SQLite

Участник сдаёт `solution.py`. Программа читает из stdin имя базы (`films0.db`, `films1.db` или `films2.db`) и печатает названия фильмов, по одному на строку. Чекер выполняет тот же запрос и сравнивает строки. Файл правильного ответа в тесте для сравнения не используется: он нужен, чтобы пара теста попала в набор.

Запрос в `solution.py` и `compare_result.py` один и тот же, включая условие `duration != ''`. Раньше образец решения это условие пропускал и получал бы WA на собственном чекере.

## Настройки задачи

Тип `PROBLEM_WITH_CHECKER`. Компилятор `make`. В образе нужны `python3`, `sqlite3` из стандартной библиотеки и `flake8`: `build.sh` гоняет `check.py`, и отсутствие `flake8` даёт CE.

Стандартный ввод и стандартный вывод включены. Тест подаётся на stdin, печать участника становится выводом.

Файлы компиляции, в этом порядке: `Makefile`, `build.sh`, `check.py`.

Файлы запуска, в этом порядке: `run.sh`, `films0.db`, `films1.db`, `films2.db`.

Чекер тоже открывает базу по имени из входного файла. Положите те же три базы в файлы чекера следом за исполняемым файлом: файлы запуска копируются к решению, а не к чекеру.

Чекер: скомпилировать `compare_result.py` компилятором Python, тип `TESTLIB_EXITCODE_CHECKER`. «Чекер выставляет баллы» выключено. Коды только из документации: `0` OK, `1` WA, `2` PE. Старые коды `4`, `5` и `6` относились к другой таблице и при типе testlib не являются PE или ошибкой проверки. Чекер читает пути из `sys.argv`, а не файлы с фиксированными именами `input`, `output` и `answer`.

Постпроцессор: первым `postprocessor.py`. Первая строка — `100`, если все тесты `ok`, иначе `0`. Вторая строка — `пройдено/всего`. Флаг `DIFFERENT` в файле переключает оценку на долю тестов и исключает набор `samples`; для него выключите оба прерывания тестирования при первой ошибке. При `DIFFERENT = False` прерывание можно оставить включённым.

Соревнование: монитор `SCORING`. «Вывод чекера» показывает OK/WA без списка верных названий.

Тесты лежат в `tests/001`–`003`: внутри только имя базы.

## Если проверка падает

- Баллы не появляются: монитор не `SCORING` или постпроцессор напечатал не число. Первая строка сейчас всегда число.
- Crash: чекер не задан, базы не лежат рядом с чекером, в задаче нет теста, либо чекер завершился с кодом кроме 0, 1 и 2.
- CE на стиле: `flake8` нашёл ошибку `E` или его нет в образе. Проверку можно убрать из `build.sh`, если стиль не нужен.
