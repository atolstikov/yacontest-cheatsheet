Реализуйте функцию `summarize(values)` в ноутбуке `solution.ipynb`. Она получает список конечных целых или вещественных чисел и возвращает словарь с четырьмя полями:

| Поле | Значение |
| --- | --- |
| `count` | Число элементов |
| `minimum` | Минимальное значение |
| `maximum` | Максимальное значение |
| `mean` | Среднее арифметическое |

Для пустого списка верните `count=0`, а остальные три значения — `None`. Исходный список не изменяйте. В результате должны быть только перечисленные поля. Для среднего при проверке допускается погрешность `1e-9` относительно значения или `1e-12` по абсолютной величине.

## Примеры

```python
summarize([2, 4, 6])
# {"count": 3, "minimum": 2, "maximum": 6, "mean": 4.0}

summarize([])
# {"count": 0, "minimum": None, "maximum": None, "mean": None}
```
