Создайте HTTP-сервис на Flask, который складывает два целых числа из пути запроса.

## Контракт сервиса

На GET-запрос по пути `/<a>/<b>` сервис должен ответить кодом 200 и строкой с суммой `a+b`. Например, ответ на `GET /2/3` — текст `5`. Не возвращайте JSON, HTML или поясняющий текст.

## Что сдать

Сдайте один Python-файл. Flask-приложение должно находиться в переменной `app`. Можно начать с такого шаблона:
```python
from flask import Flask

app = Flask(__name__)

@app.route("/<a>/<b>", methods=["GET"])
def add(a, b):
    # Верните строку с суммой двух чисел.
    ...
```
Стенд импортирует модуль и сам запускает приложение на порту 7777. Не вызывайте `app.run()` при импорте. Стандартный ввод читать не нужно; ответ проверяется как тело HTTP-ответа. Файлы с результатом создаёт проверяющая система.

## Примеры
```python
GET /2/3  ->  5
GET /7/8  ->  15
```

## Оценивание

Каждый из пяти основных тестов даёт 20 баллов, максимум — 100. Примеры в балл не входят. Возможен частичный зачёт: например, три пройденных основных теста дают 60 баллов. При этом общий вердикт может быть «Неверный ответ», если пройдены не все тесты.
