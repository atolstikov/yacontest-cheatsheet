# HTTP-сервер Flask

Используйте рецепт, чтобы запускать сервер участника внутри Контеста и проверять его HTTP-ответы.

## Что сдаёт участник

Python-модуль с Flask-приложением `app`. GET-маршрут `/<a>/<b>` возвращает сумму двух целых чисел строкой. Образец — [solution.py](solution.py). Участник не должен запускать сервер при импорте модуля.

[test.py](test.py) импортирует приложение в отдельном процессе, запускает его на `127.0.0.1:7777`, выполняет запрос из теста и сохраняет тело ответа в `output.txt`. Процесс завершается после запроса; логи пишутся в `server.log`.

## Настройте задачу

Выберите `PROBLEM_WITH_CHECKER`, компилятор `make` и образ с Python, Flask, requests и flake8.

| Настройка | Значение |
| --- | --- |
| Ввод | stdin включён; если требуется имя входного файла, задайте `run.py` |
| Вывод | файл `output.txt`, stdout выключен |
| Создание файлов | Разрешено |
| Файлы компиляции | `Makefile`, `build.sh`, `check.py` |
| Файлы запуска | `run.sh`, `test.py` |
| Чекер | `STANDARD_CHECKER`, `cmp_file` |
| Постпроцессор | Python; `postprocessor.py` |
| Основные тесты | `tests/01`–`tests/05`, маска `tests/{01-}`, ответы `*.a` |
| Примеры | Отдельный набор `samples`: `tests/sample01`, `tests/sample02` и их `.a` |
| Монитор | `SCORING` |

Отключите прерывание при первой ошибке и в задаче, и в наборах тестов. Для запуска начните с лимита 10 секунд: скрипт может ждать готовности сервера до 8 секунд и ответа до 2 секунд; проверьте достаточность общего лимита контрольными посылками.

Не добавляйте авторский `solution.py` к runtime-файлам. Он должен создаваться из посылки.

## Настройте тесты и баллы

Вход теста содержит выражение вида `request('GET', 'http://127.0.0.1:7777/2/3')`, ответ `.a` — ожидаемое тело HTTP-ответа. Формат разбирается через AST; поддерживается вызов `request` с двумя позиционными аргументами.

По умолчанию `DIFFERENT = True`: балл равен округлённой доле пройденных основных тестов, умноженной на 100. Набор с точным именем `samples` исключается. При пяти основных тестах каждый стоит 20 баллов. Если нужны только 100/0, установите `DIFFERENT = False`; в этом режиме учитываются и samples.

## Проверьте результат

Отправьте образец: ожидайте OK/100. Реализация с ответом 0 должна получить WA/0. Для частичного зачёта верните верную сумму только при сумме меньше 100: на текущих пяти основных тестах ожидайте WA/60. Примеры должны пройти, но не увеличить знаменатель.

При RE проверьте объект `app`, импорт модуля и логи сервера. При пустом выводе сверьте `output.txt` и разрешение создавать файлы. При неверном частичном балле проверьте точное имя набора `samples` и оба флага прерывания.

## Соберите и загрузите файлы

Из корня репозитория выполните:

```sh
python _packaging/package_recipe.py --check network-http-server
python _packaging/package_recipe.py network-http-server
```

Загрузите `dist/network-http-server.zip` в корень файлов задачи. Назначьте роли файлов из таблицы выше в указанном порядке; архив сам не применяет настройки. Скрипты храните с LF. Сверьте старые файлы и активные тесты: ZIP не удаляет отсутствующие в нём пути.
