Реализуйте функцию, которая изменяет готовую SQLite-базу: удаляет фильмы жанра «боевик» с чётной продолжительностью в минутах. Остальные фильмы и таблицу жанров нужно сохранить без изменений.

## Структура базы
```text
genres(id INTEGER PRIMARY KEY, title TEXT)
Films(id INTEGER PRIMARY KEY, title TEXT NOT NULL,
      year INTEGER NOT NULL, genre INT NOT NULL,
      duration INT DEFAULT NULL)
```
Поле `Films.genre` ссылается на `genres.id`. Название нужного жанра в `genres.title` — «боевик». Проверяйте чётность значения `duration`, а не года или идентификатора.

## Что сдать

Сдайте один Python-файл с функцией:
```python
def get_result(name):
    # Измените SQLite-базу по пути name и сохраните изменения.
    ...
```
Проверяющая программа создаёт рабочую копию базы и передаёт её путь в `name`. Откройте эту базу, выполните удаление и зафиксируйте изменения (`commit`) до возврата из функции. Возвращаемое значение не проверяется.

Не читайте стандартный ввод и не печатайте SQL-дамп. Стенд сам вызовет функцию и проверит содержимое базы после её завершения. Создавать собственную базу вместо переданной не нужно.

## Пример

Если в базе есть боевики длительностью 90 и 91 минута и драма длительностью 90 минут, нужно удалить только первый боевик. Второй боевик и драма остаются в базе.

## Оценивание

100 баллов за прохождение всех трёх тестов, иначе 0. Проверяется содержимое таблиц `Films` и `genres` после вызова функции.
